## 📊 Модели данных (DTO)

- - - - - - - - - - - - - - - - - - - - - - - - - - - - - - - - - - -

### InstalledMod

Скачанный пользователем мод

Хранится в локальном профиле пользователя: `(data/oghma/users/{user_id}/mods/{game_id}/{mod_id}/meta.toml)`

|       Поле       |   Тип данных    | Описание                                                              |
|:----------------:|:---------------:|:----------------------------------------------------------------------|
|    `localId`     |      `int`      | Уникальный локальный ID мода в БД пользователя                        |
|  `remoteModId`   |      `int`      | Ссылка на оригинальный ID мода Hermaeus                               |
|     `gameId`     |      `int`      | ID игры, для которой установлен данный мод                            |
|     `title`      |    `String`     | Название модификации                                                  |
|  `localVersion`  |    `String`     | Версия мода, установленная у пользователя                             |
| `currentVersion` |    `String`     | Актуальная версия мода в Hermaeus (для проверки обновлений)           |
|   `lastUpdate`   | `LocalDateTime` | Дата синхронизации метаданных с удаленным сервером                    |
| `installedFiles` | `List<String>`  | Список файлов                                                         |
|    `enabled`     |    `boolean`    | Статус активации: включен мод в игре или выключен                     |
|    `priority`    |      `int`      | Порядковый номер в Load Order (чем выше, тем приоритетнее файлы мода) |
|      `size`      |     `long`      | Локальный размер файлов модификации на диске в байтах                 |

```text
oghma/users/{user_id}/mods/{game_id}/{mod_id}/
├── files.txt
└── meta.toml
```

### Conflict

Кофликт между двумя модами

|      Поле       |   Тип данных   | Описание                       |
|:---------------:|:--------------:|:-------------------------------|
|  `firstModId`   |     `int`      | ID первого конфликтующего мода |
|  `secondModId`  |     `int`      | ID второго конфликтующего мода |
| `conflictFiles` | `List<String>` | Список конфликтующих файлов    |
