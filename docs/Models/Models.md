## Mod

Полная информация о модификации, включая все метаданные, необходимые для отображения детальной страницы мода и его
управления.

Хранится в виде отдельных файлов конфигурации для каждого мода: `data/hermaeus/mods/resources/{mod_id}/meta.toml`

|        Поле        |   Тип данных    | Описание                                                             |
|:------------------:|:---------------:|:---------------------------------------------------------------------|
|        `id`        |      `int`      | Уникальный ID мода в БД Hermaeus                                     |
|      `gameId`      |      `int`      | ID игры, для которой предназначен данный мод                         |
|    `categoryId`    |      `int`      | ID категории, к которой относится модификация                        |
|     `authorId`     |      `int`      | ID автора, загрузившего модификацию                                  |
|      `title`       |    `String`     | Название мода                                                        |
|   `requirements`   | `List<Integer>` | Список ID модов, обязательных к установке перед данным               |
|  `publishedDate`   | `LocalDateTime` | Дата и время первой публикации                                       |
|   `updatedDate`    | `LocalDateTime` | Дата последнего обновления/загрузки новой версии                     |
|      `status`      |   `ModStatus`   | Текущий статус модерации (см. Enum)                                  |
|     `version`      |    `String`     | Строковое представление текущей версии                               |
|   `endorsements`   |      `int`      | Количество одобрений (лайков) от пользователей                       |
|    `downloads`     |      `int`      | Общее количество скачиваний данного мода                             |
|       `tags`       | `List<String>`  | Список тегов мода                                                    |
|     `gallery`      | `List<String>`  | Коллекция путей к галерее мода в папке ресурсов                      |
|   `description`    |    `String`     | Полное описание мода                                                 |
| `installationFile` |    `String`     | Путь к файлу установки (на данном этапе — описание структуры в .txt) |
|       `size`       |     `long`      | Размер файла модификации в байтах                                    |

```text
Пример файловой системы мода
data/hermaeus/mods/resources/{mod_id}/
├── meta.toml
├── gallery/
│   └── image{id}.png
└── files/
    └── {filename}.txt
```

### ModStatus

Статус модификации в Hermaeus

* `ACTIVE` — Активный, доступно всем пользователям
* `HIDDEN` — Скрыт модерацией (скрыт из общего поиска)
* `ARCHIVED` — Помечен как неактуальный
* `DELETED` — Удален (помечен как удалённый)

### InstalledMod

Скачанный пользователем мод

Хранится в локальном профиле пользователя: `(data/oghma/users/{user_id}/mods/{game_id}/{mod_id}/meta.toml)`

|       Поле       |   Тип данных    | Описание                                                              |
|:----------------:|:---------------:|:----------------------------------------------------------------------|
|    `localId`     |      `int`      | Уникальный локальный ID мода в БД пользователя                        |
|  `remoteModId`   |      `int`      | Ссылка на оригинальный ID мода Hermaeus                               |
|     `gameId`     |      `int`      | ID игры, для которой установлен данный мод                            |
|     `title`      |    `String`     | Название модификации                                                  |
|  `localVersion`  |    `String`     | Версия мода, установленная у пользователя                             |
| `currentVersion` |    `String`     | Актуальная версия мода в Hermaeus (для проверки обновлений)           |
|   `lastUpdate`   | `LocalDateTime` | Дата синхронизации метаданных с удаленным сервером                    |
| `installedFiles` | `List<String>`  | Список файлов                                                         |
|    `enabled`     |    `boolean`    | Статус активации: включен мод в игре или выключен                     |
|    `priority`    |      `int`      | Порядковый номер в Load Order (чем выше, тем приоритетнее файлы мода) |
|      `size`      |     `long`      | Локальный размер файлов модификации на диске в байтах                 |

```text
oghma/users/{user_id}/mods/{game_id}/{mod_id}/
├── files.txt
└── meta.toml
```
