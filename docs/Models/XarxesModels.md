### User: Пользователь

`(data/xarxes/users.json)`

|       Поле        |  Тип данных   | Описание                                     |
|:-----------------:|:-------------:|:---------------------------------------------|
|        id         |      int      | Уникальный ID пользователя                   | 
|     username      |    String     | Уникальное имя (логин)                       | 
|   passwordHash    |    String     | Хэш пароля для безопасности                  |
|       role        |     Role      | Роль, Права доступа (USER, MODERATOR, ADMIN) | 
| registrationDate  | LocalDateTime | Дата регистрации аккаунта (LocalDateTime)    | 
|  installedModIds  | List<Integer> | Список ID установленных модов (InstalledMod) | 
| endorsementModIds | List<Integer> | Список ID одобренных (лайкнутых) модов       | 
|  favoriteModIds   | List<Integer> | Список ID любимых модов                      | 
|  uploadedModIds   | List<Integer> | Список ID загруженных в Hermaeus модов       | 
|       theme       |     Theme     | Выбранная тема приложения                    |

### enum Role: Роль пользователя

* Пользователь \ Может устанавливать и загружать свои моды, использовать свой Oghma
* Модератор \ Может модерировать модификации на Hermaeus, скрывать из общего списка. Добавлять новые игры.
* Администратор \ Умеет всё, т.е создавать\менять\удалять всё.
